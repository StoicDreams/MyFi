# Share Image

<webui-page-segment>

Social sites, chat apps, and search results show this image when someone shares a link to the site. It is `webapp/root_files/img/myfi-share.png`, 1200x630, drawn by `screenshots/brand.shots.mjs` from `Logo.svg`, the site name in `appConfig.json`, and the theme colors in `webapp/css/app.css`. Facebook, LinkedIn, X, and Slack don't show SVG images, so `og:image` and `twitter:image` in `webapp/index.html` point at this PNG, never at `Logo.svg`.

</webui-page-segment>

## Change the tagline

<webui-page-segment>

Set `$shareTagline` to the new line under the site name, then run the script. It:

1. Writes the tagline into `TAGLINE` in `screenshots/brand.shots.mjs`.
2. Sets `og:image:alt` in `webapp/index.html` to the site name and tagline, which screen readers and some link previews read.
3. Draws the image again.
4. Prerenders the pages again, since each one copies the meta tags from `index.html`. The tests fail on stale prerendered pages.

```pwsh
$shareTagline = 'Backend-as-a-Service for developers who build with purpose'
$ErrorActionPreference = 'Stop'
if (-not $shareTagline.Trim()) { throw 'Set $shareTagline to the line under the site name.' }
if (-not (Test-Path 'node_modules')) { npm ci; if ($LASTEXITCODE) { throw 'npm ci failed.' } }

$shots = 'screenshots/brand.shots.mjs'
$quoted = $shareTagline.Trim() | ConvertTo-Json
$js = Get-Content $shots -Raw
if ($js -notmatch 'const TAGLINE = [^\r\n]*;') { throw "$shots has no TAGLINE line." }
Set-Content $shots ([regex]::Replace($js, 'const TAGLINE = [^\r\n]*;', { "const TAGLINE = $quoted;" })) -NoNewline

$appName = (Get-Content 'webapp/root_files/appConfig.json' -Raw | ConvertFrom-Json).appName
$alt = [System.Net.WebUtility]::HtmlEncode("${appName}: $($shareTagline.Trim())")
$html = Get-Content 'webapp/index.html' -Raw
if ($html -notmatch '<meta property="og:image:alt" content="[^"]*">') { throw 'webapp/index.html has no og:image:alt tag.' }
Set-Content 'webapp/index.html' ([regex]::Replace($html, '<meta property="og:image:alt" content="[^"]*">', { "<meta property=`"og:image:alt`" content=`"$alt`">" })) -NoNewline

npx playwright test --config playwright.screenshots.config.mjs screenshots/brand.shots.mjs
if ($LASTEXITCODE) { throw 'Drawing the share image failed.' }
if (-not (Get-Command webapp_post_build -ErrorAction SilentlyContinue)) {
    throw 'Prerendering needs webapp_post_build: cargo install webapp_post_build --git https://github.com/StoicDreams/WebUI'
}
Push-Location 'webapp'
try { webapp_post_build prerender; if ($LASTEXITCODE) { throw 'Prerendering the pages failed.' } } finally { Pop-Location }
Write-Host "Share image updated: webapp/root_files/img/myfi-share.png" -ForegroundColor Green
```

Look at the image before committing, to check the tagline fits. Then run the tests from the **Tests** page.

</webui-page-segment>

## Redraw it without changing the tagline

<webui-page-segment>

Run this after changing `Logo.svg`, the site name in `appConfig.json`, or the theme colors in `webapp/css/app.css`. The **Release** page's Screenshots script also redraws it, along with the page screenshots.

```pwsh
npx playwright test --config playwright.screenshots.config.mjs screenshots/brand.shots.mjs
```
