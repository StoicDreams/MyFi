# Run Tests

<webui-page-segment>

Tests use [Playwright](https://playwright.dev) and need no build or running server, since they serve the site directly from `webapp/`. Only the framework loads from the CDN. Analytics and other outside requests are blocked, and `api.myfi.ws` returns an empty response.

```pwsh
npm install
npx playwright install chromium
```

On Linux the tests use `/usr/bin/chromium` if it exists, so the second command can be skipped. Set `PW_CHROMIUM_PATH` to use a different browser.

## Commands

Run everything against the live CDN, which is what the deployed site uses

```pwsh
npm test
```

Open the interactive runner, with watch mode and a timeline for each test

```pwsh
npm run test:ui
```

Run everything against the `MyFiCDN` checkout next to this repo. Use this to try framework changes before pushing them

```pwsh
npm run test:local-cdn
```

Open the last report, with a screenshot and trace for each failure

```pwsh
npm run test:report
```

Run one file

```pwsh
npx playwright test tests/site.spec.mjs --project=live-cdn
```

Run tests by name

```pwsh
npx playwright test -g "loads" --project=live-cdn
```

Run the Rust tests

```pwsh
cargo test
```

## Test files:

- `tests/site.spec.mjs` checks the config and SEO files, links between pages, min files, and that every linked page loads with a title, no errors, and all of its components. It is the same in every site, so change it in every site at once.
- `tests/support/site.mjs` provides `test`, `expect`, and `openPage(page, route)`, and serves the site from `webapp/`. It is also the same in every site.
- `tests/site.config.mjs` holds this site's settings.
- Add checks for this site's own pages and components in new `tests/*.spec.mjs` files.

Any uncaught error during a test fails that test, even if its checks pass.

A shared check this site is known to fail is listed in `knownBugs` in `tests/site.config.mjs`, with the reason. Once the bug is fixed the test reports `Expected to fail, but passed`, which is the cue to delete that entry. In a site's own spec files, use `test.fail(true, 'Known bug: ...')` instead.
